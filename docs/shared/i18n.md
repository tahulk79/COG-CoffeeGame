# Đa ngôn ngữ (Anh / Việt)

Từ 04/11/2026 game có hai ngôn ngữ: **English (mặc định)** và **Tiếng Việt**. Chọn trong ⚙️ Cài đặt → 🌐 Ngôn ngữ.

## Cách hoạt động

- Ngôn ngữ lưu ở `settings.lang` (`'en' | 'vi'`, xem [contracts.md](contracts.md) §4). Save cũ không có trường này → tiếng Anh.
- Ngôn ngữ **cố định trong một lần tải trang**. Đổi ngôn ngữ thì lưu rồi tải lại trang; tiến trình đã được lưu sau mỗi thao tác nên không mất. Vì vậy được gọi `t()` ở cấp module (bảng nội dung, hằng số).
- `src/i18n/index.js`:
  - `t(key, params)` — chuỗi có `{tên}` được thay bằng `params.tên`; giá trị có thể là hàm `(params) => chuỗi` (số nhiều tiếng Anh) hoặc mảng/object (danh sách câu, mẹo). Thiếu khóa → lấy tiếng Anh → tiếng Việt → trả lại chính khóa.
  - `getLang()`, `numberLocale()` (`'en-US' | 'vi-VN'`), `formatNumber(value, options)` — không viết thẳng `toLocaleString('vi-VN')`.
  - `applyI18n(root)` dịch HTML tĩnh: `data-i18n="khóa"` (chữ), `data-i18n-attr="aria-label:khóa;title:khóa2"` (thuộc tính). `src/main.js` gọi một lần lúc khởi động và đặt `<html lang>`.
- CSS có chữ (`content:`) viết tiếng Anh làm mặc định, thêm luật `:lang(vi) …` cho tiếng Việt.
- Chạy test trong Node (không có localStorage) → tiếng Anh.

## File chuỗi

`src/i18n/locales/<tên>.js` xuất `{ en: {...}, vi: {...} }`. Mỗi khóa phải có ở cả hai ngôn ngữ, tiền tố theo file:

| File | Tiền tố | Dùng cho |
|---|---|---|
| `html.js` | `html.` | `index.html` |
| `common.js` | `common.`, `settings.`, `dialogue.`, `loading.`, `app.`, `ui.`, `shared.`, `character.` | UI dùng chung, app, cảnh dùng chung |
| `selection.js`, `intro.js`, `heaven.js` | `selection.`, `intro.`, `heaven.` | Màn 00–02 |
| `farm.js` / `farm-rules.js` | `farm.` / `farmRules.` | UI/cảnh farm / luật, nội dung, model farm |
| `cafe.js` / `cafe-recipes.js` | `cafe.` / `cafeRecipes.` | UI/cảnh quán / công thức, phục vụ |

## Quy ước khi thêm chuỗi

- Không viết chữ hiển thị thẳng trong code; thêm khóa vào file locale của màn, có cả `en` và `vi`.
- Logic không được so sánh/khớp chữ hiển thị; dùng id hoặc mã.
- Mã người nói trong hội thoại `'BẠN'`, `'THẦN CHẾT'`, `'NHÂN VIÊN Y TẾ'` là id, không dịch; `src/ui/dialogue.js` tự hiển thị tên theo ngôn ngữ.
- Tên người, địa danh Việt (Hà Nội, tên nhân vật ngẫu nhiên) giữ nguyên ở cả hai ngôn ngữ.
- Comment trong code không cần dịch.
