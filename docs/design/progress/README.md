# Báo cáo tiến độ

Mỗi **ngày** là **một file** `YYYY-MM-DD-ten.md` (ví dụ `2026-11-05-quang.md`), chép từ [_template.md](_template.md). Commit tiêu đề `progress: …`.

- Làm nhiều lần trong ngày thì thêm gạch đầu dòng vào file của ngày đó; không cần ghi giờ.

- Chỉ ghi cái **mới** kể từ báo cáo trước: việc xong, việc đang làm, câu hỏi cần quyết, chỗ vướng. Mục trống thì xóa.
- Không chép lại bảng trạng thái GDD; báo cáo chỉ trỏ mã `F-xx` / `D-xx`. Trạng thái tổng vẫn ở GDD mục 0.3.
- Dòng **Cập nhật** là câu tóm tắt; hộp thư thiết kế in nguyên câu này khi đồng bộ về.
- Sang ngày mới thì viết file mới; file của ngày đã qua không sửa lại.
