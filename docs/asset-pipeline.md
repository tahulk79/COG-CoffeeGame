# Phòng 3D: Meshy → Blender MCP → game

Quy trình như một phòng ban nhỏ: agent `asset-3d` lo brief và hậu kỳ, người dùng chỉ chạy Meshy (tốn credit), dev gắn model bằng `replaceAsset`. Quy ước kích thước, pivot và danh sách slot ở [scene-assets.md](scene-assets.md).

## Vai trò

| Vai | Ai | Việc |
|---|---|---|
| Art brief | `asset-3d` | Chọn slot cần model, viết prompt Meshy theo style guide, ghi vào hàng đợi |
| Tạo mẫu | Người dùng | Chạy prompt trên Meshy, chọn bản đẹp nhất, tải GLB (kèm texture) |
| Hậu kỳ | `asset-3d` + Blender MCP | Scale, pivot, hướng, giảm poly, gộp vật liệu, đặt tên nhóm con, xuất GLB |
| Animation, bake, render | `asset-3d` + Blender MCP | Clip animation trong GLB, AO/lightmap, flipbook VFX (`public/vfx/`), icon vật phẩm (`public/ui/icons/`) |
| Hiệu ứng runtime | `vfx-artist` | Particle, shader, hậu kỳ, ánh sáng, tween trong Three.js (`src/shared/vfx/`), dùng texture của asset-3d |
| Gắn vào game | `farm-dev` / `cafe-dev` | Tải GLB, `replaceAsset(slot, model)`, gọi hiệu ứng của vfx-artist; luật chơi không đổi |
| Nghiệm thu | `playtester` | Model đúng chỗ, không chặn đường/điểm tương tác, không tụt FPS |

## Luồng

1. `asset-3d` thêm dòng vào **Hàng đợi asset** (trạng thái `brief`).
2. Người dùng chạy prompt trên Meshy, lưu file vào `assets-src/meshy/<tên ở cột GLB>.glb` (vd. `coffee-tree.glb`), đổi trạng thái thành `có file`.
3. Gọi `/game-team` hoặc agent `asset-3d`: mở Blender, chuẩn hóa, xuất `public/models/<feature>/<tên>.glb`, chụp xem lại, trạng thái `đã xuất`.
4. Dev gắn slot, trạng thái `trong game`. Playtester kiểm tra.

`assets-src/` giữ file gốc và `.blend`, không nằm trong `public/` nên không vào bản build.

## Style guide (dùng chung cho mọi prompt)

Đi cùng UI gỗ + giấy da: **stylized low-poly, ấm, màu đất và xanh lá dịu, cạnh bo tròn, tỉ lệ hơi chibi, ánh sáng mềm, không chữ trên model**. Mẫu prompt:

```
<vật thể>, stylized low-poly game asset, warm cozy coffee farm, rounded edges,
soft earthy palette (brown wood, cream, sage green), hand-painted texture, no text, single object, neutral pose
```

Thêm vào mỗi prompt: chiều cao/kích thước tương đối so với người cao 2 m, hướng mặt chính.

## Blender làm gì, Three.js làm gì

Blender **dựng sẵn** (chạy một lần, xuất file): model, animation, ánh sáng bake, texture flipbook khói/hơi/lửa, icon và ảnh render. Three.js **chạy trong game** (mỗi khung hình): particle, shader gió/nước, bloom/outline, ánh sáng theo giờ, số bay, rung camera. Hiệu ứng phải phản ứng theo trạng thái game (lò đang rang mới bốc khói) nên luôn nằm ở runtime; Blender chỉ cung cấp hình.

| Loại | Kích thước | Nơi lưu |
|---|---|---|
| Flipbook VFX | atlas 4×4 hoặc 8×8, 512–1024px, PNG nền trong suốt | `public/vfx/<tên>.png` |
| Icon vật phẩm | 256px, góc 3/4, nền trong suốt, cùng một bộ đèn | `public/ui/icons/<id>.png` |
| Clip animation | tên `idle`, `walk`, `work`, `sit`, `drink`… | trong GLB của model |
