## Complete paths supported by current code/tests

1. Enter the café → inspect an object or hear the story → self-brew / watch → finish or leave early → hear ending → goodbye → keepsake → next visit. No calendar gate or quiz-win prerequisite.
2. Fourteen distinct episode profiles support self/watch completion, including AeroPress and the five-pour methods. The model tests execute all 28 combinations.
3. Open an archived visit → read/rehearse its brewing experience → return without overwriting its completed story.
4. Use the separate First Pour station → record reflection → save → compare/rebrew or attempt one changed variable. Missing/deleted baselines remain explicit.
5. Record actual brewing separately with optional measurements and self-reported tasting; simulation is not automatically promoted into real observations.

Browser playthrough and layout evidence from earlier release work remains documented in `PLAY-SCREEN.md` and the existing smoke scripts. This review did not rerun those browser matrices; model execution is not a substitute for UI playthrough.
